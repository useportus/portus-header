# Portus Header — imagens do produto

Ícones iniciais do Portus Header.

## Arquivos

- `icon.svg`
- `icon-512x512.svg`
- `icon-512x512.png`
- `icon-256x256.png`
- `icon-128x128.png`
- `banner-772x250.png`
- `banner-1544x500.png`
- `product-cover-portus-header-pro.png`
- `hero-portus-header-pro.png`

## Uso

- `icon-128x128.png`: ícone padrão para update privado/WordPress.
- `icon-256x256.png`: versão 2x do ícone.
- `icon-512x512.png`: imagem do produto ou asset comercial.
- `icon.svg`: fonte vetorial editável.
- `banner-772x250.png`: banner padrão para modal/update privado.
- `banner-1544x500.png`: banner 2x para modal/update privado.
- `product-cover-portus-header-pro.png`: capa do produto WooCommerce.
- `hero-portus-header-pro.png`: imagem horizontal para landing/social.
