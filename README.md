# Portus Header

Portus Header is a responsive, customizable header plugin for WordPress.

Create a branded navigation with native WordPress menus, separate desktop and mobile logos, a configurable CTA button, optional sticky behavior, a mobile drawer, and shortcode or automatic display modes.

[WordPress.org Plugin](https://wordpress.org/plugins/portus-header/) · [Product page](https://useportus.com/portus-header/) · [Documentation](https://useportus.com/docs/portus-header/) · [Support](mailto:plugins@useportus.com)

## Features

- Responsive header for desktop and mobile.
- Native WordPress menu integration, including submenu support.
- Desktop and mobile logo controls.
- Optional CTA button with custom link behavior.
- Automatic display or the `[portus_header]` shortcode.
- Optional sticky header.
- Customizable colors for desktop, mobile, drawer, submenu, and CTA states.
- Mobile navigation drawer.
- Astra compatibility option and a cautious CSS selector fallback for other themes.
- Scoped styles and assets loaded only where required.

## Requirements

- WordPress 6.0 or newer.
- PHP 7.4 or newer.
- A theme that prints the standard WordPress header and footer hooks.

## Installation

The recommended installation method is through WordPress.org:

1. Open **Plugins > Add New** in WordPress.
2. Search for **Portus Header**.
3. Install and activate the plugin.
4. Open **Appearance > Portus Header**.
5. Configure the display mode, menus, logo, CTA, colors, and mobile drawer.
